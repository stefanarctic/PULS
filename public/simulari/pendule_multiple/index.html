Informații

Ce vezi aici

  • Toate pendulurile pornesc aproape identic, dar cu o mică diferență (perturbare).
  • După puțin timp, traiectoriile devin complet diferite → haos determinist.
  • Urmele sunt pentru bobul 2 (capătul pendulului dublu), de aceea arată „nebun".

Model (pe scurt)

Coordonate: x₁ = L₁ sinθ₁, y₁ = L₁ cosθ₁
x₂ = x₁ + L₂ sinθ₂, y₂ = y₁ + L₂ cosθ₂
Integrăm numeric (RK4): θ′ = ω, ω′ = f(θ₁,θ₂,ω₁,ω₂) dt = pas de timp (s)
